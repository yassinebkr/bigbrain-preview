# Documentary research: bounded release scope

## Closure decision — 29 October 2026

The direct research iteration closes with a bounded product scope: targeted
documentary questions, captured official references where requested, literal
citations, finite execution and explicit partial or blocked results. Complex
multi-axis comparisons remain experimental. The original full-coverage campaign
has outstanding criteria; its results retain that qualification.

## Delivered behavior

- Capture-bound evidence survives working-context eviction and session storage.
- Citation acceptance requires a model-exposed literal passage from its current
  capture. Semantic relevance remains a model judgment.
- Source inventory separates acquisition, exposure and source assessment.
- Immutable result artifacts preserve public delivery through orchestration
  compaction. Chat and Atelier receive terminal outcomes.
- Input, output and cache usage retain unknown dimensions. Codex thresholds are
  monitored; an in-flight call can exceed its allowance before subsequent calls
  stop. Cost references require a dated, available model price.
- Optional extensions outside the original request can be labelled
  "à définir au besoin". Accuracy-critical qualifications remain required.

## Measured acceptance and limits

The six-case frontend campaign produced three accepted cases, one Python oracle
reservation and two failures. Subsequent bounded confirmation fixed source
judgment feasibility and Git public delivery after real compaction. The Python
oracle requires a regular-file distinction beyond its explicit question; that
frozen criterion remains recorded as outstanding.

The latest PostgreSQL confirmation finished partial in 30.57 seconds: six acquired
sources exposed and evaluated, eleven literal citation anchors verified, four
research calls, 79,917 reported input tokens and 1,929 output tokens. Chat and
Atelier displayed the partial result. TRUNCATE identity defaults, transactional
qualifications and some sequence effects remain incompletely evidenced.
Acquisition success and valid anchors alone do not establish complete answers.

Working-set selection still uses lexical ranking and structural bundles. A
12,000-byte packet can omit necessary passages despite successful acquisition.
Recent source-bound intentions and unexposed sources receive priority; general
selection reliability across unseen questions remains unvalidated. A separate
nondefault-workspace dispatch mismatch occurred in the campaign harness.

The final backend regression run passed 1,950 tests with eight skips. Frontend
results and remote CI are reported separately at release time. Authored offline
replays establish boundary mechanics and capacity; autonomous selection quality
requires actual live evidence.

## Deferred work

Further semantic selection, complex comparison coverage, source-specific
acquisition adapters and Laya integration remain future evaluated extensions.
Each requires a frozen acceptance set, retained failures and bounded live cost.
The next architecture discussion concerns task focus, background work, user
interruptions and an evolving work surface. Implementation awaits its decisions.
